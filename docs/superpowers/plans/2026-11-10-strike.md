# Викреслювач (`videoworks strike`) — план реалізації

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Локальна сторінка, де ведуча червоним пензлем викреслює слова, які не йдуть в ефір; позначки лягають у `strikes.json`, а пілот `soundtrack-test` кладе на їх місце чисту музику.

**Architecture:** Чиста логіка позначок у `strikes.py` (фрази, відрізки глушіння, перенесення на новий транскрипт, атомарний запис). Тонкий HTTP-сервер зі стандартної бібліотеки `strike_server.py` поверх `preview.send_video` / `preview.Server`. Сторінка — статичні файли в `src/videoworks/web/strike/`, де вся арифметика винесена в `logic.js` без DOM і перевіряється в Node. Пілот `soundtrack/trial.py` отримує криву викреслення.

**Tech Stack:** Python 3.12, pydantic, typer, `http.server`; ванільний JS (ES-модулі), SVG, WebAudio, Pointer Events; pytest, `node --test`.

**Spec:** `docs/superpowers/specs/2026-11-10-strike-design.md` — читати разом із планом.

## Global Constraints

- Працювати в гілці `strike`, не в `main`.
- Сервер лише на `127.0.0.1`, лише стандартна бібліотека. Нових залежностей Python немає. У JS — жодних пакетів і жодного кроку збирання.
- Правила рахує Python: `spans`, фрази, лічильники. Сторінка їх не дублює — малює відповідь сервера.
- Значення зі спеку: `pad = 0.15`, `merge_gap = 0.25`, пауза фрази `0.6` с, стеля фрази `14` слів, «музичний» проміжок `> 2.0` с, бліде слово `prob < 0.5`, поріг мазка `6` px, реакція ручної позначки `0.3` с, крок краю `0.1` с, рампа в плеєрі `0.03` с, рампа в пілоті `0.04` с, контекст перевірки `1.5` с, автозбереження через `0.5` с, порт `8772`.
- Усі координати часу — сирий таймлайн (`transcript.raw.json`).
- Наявні команди й файли не змінюють поведінки; `soundtrack-test` без `strikes.json` дає той самий результат.
- Проєкт форматовано вручну: `ruff format` — **лише на власних нових файлах**, ніколи на всьому дереві. `ruff check` на зміненому — чистий. Рядок до 100 символів.
- Докстринги, коментарі, тексти інтерфейсу й повідомлення комітів — українською; коміти в наказовому стилі («Додати…»), із рядком `Co-Authored-By: Claude Fable 5.2 <noreply@anthropic.com>`.
- Кольори на сторінці — лише через токени в `:root` (як у `studio`).
- Файли, які читає людина, відкривати з `utf-8-sig`.

## Review Focus

1. **ASR віддає слова нульової тривалості, з перетином у часі або не по порядку** → відрізок глушіння все одно не коротший за `2 × pad`, `spans` відсортовані й без перетинів. (Task 1)
2. **`strikes.json` зіпсований руками або порожній** → команда відмовляє зі зрозумілою причиною до запуску сервера й нічого не перезаписує. (Task 2, Task 7)
3. **Сервер зупинили посеред роботи** → намір лишається в `localStorage`, плашка стоїть, після відновлення досилається останній стан, а не черга проміжних. (Task 5)
4. **Ручна позначка або запас на самому початку чи кінці запису** → обрізається до `[0, duration]`, не дає відʼємного часу й не зникає. (Task 1, Task 4)
5. **Позначка лише частково у вікні пілота або там, де трек не грає** → обрізається по вікну; без покриття — тиша й рядок у звіті, а не кімнатний запис із голосом. (Task 8)

  - `@dataclass(frozen=True) class Phrase: start: float; end: float; first: int; count: int` — `first` — глобальний індекс першого слова в `transcript.words()`
  - `phrases(transcript: Transcript) -> list[Phrase]` — слова без тексту (порожні після `strip()`) пропускаються, але індексація лишається глобальною

  - `rematch(old: Strikes, transcript: Transcript, transcript_sha: str) -> tuple[Strikes, int]` — друге значення: скільки слів стали ручними відрізками
  - `load(path: Path, *, transcript: Transcript, transcript_sha: str, source: str) -> tuple[Strikes, int]` — немає файлу → порожні `Strikes`; відбиток інший → `rematch`; зіпсований файл → `ValueError` з назвою файлу
  - `indices(strikes: Strikes, transcript: Transcript) -> list[int]` — глобальні індекси викреслених слів
  - `from_indices(chosen: Sequence[int], manual: Sequence[tuple[float, float]], *, transcript: Transcript, transcript_sha: str, source: str) -> Strikes`
  - `state(transcript: Transcript, strikes: Strikes, *, title: str, unglued: int = 0) -> dict`:

    ```jsonc
    { "title": "aerobic-6", "duration": 2288.293, "transcript": "<sha>",
      "words":   [{ "w": "блін", "start": 412.31, "end": 412.62, "dim": false }],   // усі слова, індекс = позиція
    ```
