# Тул транскрибації та генерації субтитрів

Перший компонент, який будуємо власноруч. Він же — фундамент для всього іншого:
без word-level транскрипту агентний монтаж не працює.

## Що має вміти

1. Прийняти відео або аудіо, витягти нормалізовану доріжку (FFmpeg, 16 кГц моно).
2. Транскрибувати з таймкодами **на рівні слова**, не тільки сегмента.
3. Розставити спікерів (діаризація), коли їх більше одного.
4. Віддати два виходи:
   - `transcript.json` — канонічна структура для агента (слова, таймкоди, спікери,
     впевненість);
   - субтитри `SRT` / `VTT` / `ASS` — для людей і для вжигання в кадр.
5. Уміти вжигати субтитри у відео (FFmpeg `libass`) зі стилями.

`transcript.json` — не побічний продукт, а головний. Субтитри з нього генеруються,
а не навпаки.

## Вибір бекенда

Абстрагуємо ASR за інтерфейсом (референс підходу — `subsai`, але код не копіюємо, там GPL).
Три реальні кандидати:

| Бекенд | Плюси | Мінуси |
|---|---|---|
| **faster-whisper** (MIT) | швидкий, `word_timestamps=True`, batched, int8/CPU-режим, large-v3 / turbo / distil | немає діаризації; таймкоди слів грубіші за forced alignment |
| **whisperX** (BSD-2) | forced alignment wav2vec2 → <100 мс, VAD, діаризація через pyannote, 70x realtime | pyannote-ваги **gated на HF**, важкий CUDA-стек, якість alignment залежить від наявності фонемної моделі для мови |
| **MOSS-Transcribe-Diarize** (Apache-2.0) | транскрибація + діаризація **одним проходом**, 50+ мов, JSON/SRT/ASS з коробки, без gated-ваг | новий (липень 2026), 0.9B, потребує Python 3.12+ та Transformers 5.x, на CPU повільний |

**План:** дефолт — `faster-whisper` (найдешевший старт, працює і без GPU).
`whisperX` — коли треба точні межі слів для різки. `MOSS-Transcribe-Diarize` —
перший кандидат, щойно заміряємо його на українській; він знімає біль із gated-вагами pyannote.

Перше практичне завдання: **бенчмарк усіх трьох на українському матеріалі** —
WER, точність меж слів, якість діаризації, час на хвилину аудіо. Без цих цифр вибір
буде вгадуванням.

## Формат transcript.json

Чернетка, уточнити після бенчмарку:

```jsonc
{
  "source": "media/interview.mp4",
  "duration": 1834.52,
  "language": "uk",
  "backend": { "name": "faster-whisper", "model": "large-v3", "version": "1.x" },
  "speakers": [{ "id": "S1", "label": "Ведучий" }],
  "segments": [
    {
      "id": 0,
      "start": 12.44,
      "end": 17.90,
      "speaker": "S1",
      "text": "Привіт, сьогодні розбираємо...",
      "words": [
        { "w": "Привіт", "start": 12.44, "end": 12.91, "prob": 0.98 }
      ]
    }
  ]
}
```

      не розривати словосполучення (референс алгоритму — regrouping зі stable-ts)
- [ ] вжигання в кадр через FFmpeg `libass` + стилі/бренд-профіль
- [ ] CLI: `videoworks transcribe <file> --lang uk --diarize --format srt,ass,json`

## Підводні камені

- **Українська + wav2vec2 alignment у whisperX** — треба перевірити, чи є фонемна
  модель; якщо ні, forced alignment деградує до сегментного рівня.
- **Числа, абревіатури, англіцизми** в українській мові Whisper часто пише
  непослідовно. Знадобиться пост-обробка або словник термінів проєкту.
- **Розбивка рядків** — головна причина, чому автосубтитри виглядають дешево.
  Це не ASR-задача, а окремий алгоритм, і саме на нього піде більшість часу.
- **Тиша й музика** — VAD (Silero у faster-whisper) обовʼязковий, інакше Whisper
  галюцинує текст на музичних вставках.
